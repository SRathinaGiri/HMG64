# HMG5 control and window syntax (generated)

Generated by `scripts/extract_syntax.py` from HMG5's `INCLUDE\*.ch` - the clauses each command
really accepts. `[ ... ]` = optional, `A|B` = one of, `<x>` = your value/expression,
`<{x}>`-type clauses (ON ..., ACTION) take an expression or a codeblock. Clause order is free.
Where a control has several command forms (e.g. GRID with/without ROWSOURCE), all are listed.

Contents: [WINDOW](#window), [BUTTON](#button), [LABEL](#label), [TEXTBOX](#textbox), [EDITBOX](#editbox), [RICHEDITBOX](#richeditbox), [CHECKBOX](#checkbox), [RADIOGROUP](#radiogroup), [COMBOBOX](#combobox), [LISTBOX](#listbox), [GRID](#grid), [BROWSE](#browse), [DATEPICKER](#datepicker), [TIMEPICKER](#timepicker), [MONTHCAL](#monthcal), [SPINNER](#spinner), [SLIDER](#slider), [PROGRESSBAR](#progressbar), [TAB](#tab), [TREE](#tree), [FRAME](#frame), [IMAGE](#image), [HYPERLINK](#hyperlink), [IPADDRESS](#ipaddress), [TIMER](#timer), [MENU](#menu), [TOOLBAR](#toolbar), [MEDIA](#media), [ACTIVEX](#activex), [WEBVIEW](#webview), [CHART](#chart)
